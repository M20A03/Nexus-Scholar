## ✨ Key Features

- **Full-stack academic management:** student profiles, course registrations, syllabus tracking
- **Integrated Gemini AI Tutor & Research Synthesizer for instant paper breakdowns**
- **FastAPI microservices architecture with automated Swagger documentation**
- **Role-based access controls for Students, Faculty, and University Administrators**
- **Dockerized deployment pipeline with Google Cloud Run & Vercel edge deployment**

## 💻 Getting Started Locally

### Prerequisites
- Node.js (v18.0.0 or higher) / Python 3.10+ (where applicable)
- Git installed on your system

### Installation & Run

```bash
git clone https://github.com/M20A03/Nexus-Scholar.git
cd Nexus-Scholar/frontend
npm install
npm run dev
```
